# 魔法弾・敵ヒット演出

- 白い芯＋水色の縁のドット魔法弾。短い水色の残像。
- 出始め0.18秒は発射位置の周りで小さく旋回。その後、敵を追尾しながら二次のイーズインで加速（100→500px/s、加速区間0.45秒）。
- 発射位置は描画中の精霊の周回位置に対応。
- 命中は移動距離を含めて判定し、加速で敵を飛び越して当たらなくなることを防止。
- 敵への命中は0.08秒点灯／0.08秒通常／0.08秒点灯の赤いフラッシュ。スライム・コウモリ・ゴブリンで共通。
- 敵のダメージは白いドット数字＋暗い縁。主人公と同じ字形・大きさ・上昇速度（28px/s）・1秒フェード。
- 主人公の赤文字＋白縁は維持。
- ダメージ量、発射間隔、敵撃破時のXPは維持。倒した敵は従来どおり即時消去し、白いダメージ数字は残る。
- 対象が既に倒れている弾は消去。ポーズ中は魔法弾の移動を停止。
- 変更ファイル: `js/systems-magic-v1.js`, `js/render-magic-v1.js`, `index.html`（canonicalのsystems.js/render.jsも同期）。
- 画像生成は使わず、既存Canvas描画を拡張したピクセル効果。
- 検証: 旋回・加速・移動する敵への追尾・飛び越し防止・重複命中/XP防止・死亡対象消去・ポーズ・点滅区間・文字色のテスト、および3種類の敵のブラウザー表示。
- 公開: https://kenntoko.github.io/dwarf-delver/?v=magic-flight-1
