# User interface text preference

- Render all newly added in-game visible text in a pixel/dot-art style by default, including labels, numbers, buttons, and dialogs. For Japanese text, use an appropriate pixel font rather than silently falling back to a smooth system font.
- Preserve readable accessible labels and semantic text for assistive technology.
- Current level is displayed directly below the EXP bar; keep it synchronized with level-ups.

- New character animation must use pixel-art frame changes only. Do not add smooth rotation, scaling, movement interpolation, or generated in-between frames unless the user explicitly requests it. Existing approved effects remain allowed.
